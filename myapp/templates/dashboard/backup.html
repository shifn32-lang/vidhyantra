Whatever you enter is checked with Dropbox first and saved only if it connects. After switching accounts the backup list below shows what that account holds.

  1. Type the App Key and App Secret from your app at dropbox.com/developers/apps.
  2. Press Get Dropbox code, then press Allow in the window that opens. Dropbox shows a short code — copy it.
  3. Paste the code into the last box and press Save & connect. It is turned into a permanent connection for you.
